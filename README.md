# gomisat

A CDCL SAT solver in Go, originally a port of MiniSat 2.2, being developed into a
research platform for weighted model counting on sequences of related formulas.

**Goal: exploit systematic structural similarity across reliability WMC queries.**

Reliability evaluation of multi-state systems and fault trees does not ask one
counting question, it asks a long sequence of them, each differing from the last
by a change generated by a known rule: a threshold, a `k`-out-of-`n` bound, a
configuration, a mission phase. The aim of this project is to reuse the
decomposition and the component cache across such a sequence. See
[DESIGN.md](DESIGN.md) for the scope, the phase plan and what is deliberately out
of scope — in particular, competing on pure SAT performance is not a goal.

## Status

The solver decides SAT/UNSAT, reports a model, solves under assumptions and
reports an UNSAT core, and can be reused across queries. All 2185 SATLIB
instances in `testdata/satlib` are answered correctly, and 1221 of the 1234
instances of the larger corpus are decided within 10 s each.

Learnt clauses are managed by literal block distance in three tiers; on the
larger corpus that decides 12 more instances than MiniSat's activity-only policy
and cuts the total time from 1071 s to 877 s, with a measured 2.1x cost per
conflict that the next piece of work is meant to remove. Counting is not
implemented yet; see the phase table and the measurement in DESIGN.md.

## Usage

```console
$ make build
$ ./bin/gomisat -model testdata/aim-50-1_6-yes1-4.cnf
c vars 50 clauses 80
c conflicts 8 propagations 138 decisions 18 restarts 1
c time 0.000087 s
s SATISFIABLE
v -1 2 -3 -4 -5 6 ... 0
```

The exit status follows the SAT competition convention: 10 satisfiable,
20 unsatisfiable, 0 unknown.

As a library:

```go
s := gomisat.NewSolver()
options := gomisat.DefaultSolverOptions()
for _, clause := range clauses { // clauses are DIMACS codes, e.g. []int64{1, -2}
    s.AddClauseFromCode(clause, options)
}

switch s.Solve(options) {
case gomisat.LTrue:
    model := s.Model() // map[Var]LBool
    _ = model
case gomisat.LFalse:
    // unsatisfiable
}

// A sequence of queries on the same clause set. The assumptions are replaced on
// every call, and the solver returns to the root level after each one.
for _, assumptions := range queries {
    if s.SolveWithAssumptions(assumptions, options) == gomisat.LFalse {
        core := s.UnsatCore() // the subset of assumptions that suffices
        _ = core
    }
}
```

## Development

```console
$ make check        # go vet + the regression suite on a sample of each family
$ make test-full    # the same suite over all 2185 committed instances
$ make bench-suite  # sweep the committed corpus, verify answers, compare to bench/baseline.csv
$ make baseline     # record a new bench/baseline.csv
```

The committed instances are too easy to judge a change to the search by, so the
harder corpus is fetched separately (about 99 MB, from SATLIB, pinned by checksum
in `corpus/manifest.tsv`). It lands in `$GOMISAT_CORPUS`, by default
`~/.cache/gomisat/corpus`, rather than in the working tree.

```console
$ make corpus         # fetch it (idempotent)
$ make corpus-sweep   # record bench/corpus-t10.csv, checking every decided answer
$ make corpus-compare # re-run and compare against the recorded results
```

The regression suite checks four invariants — known status, model validity,
agreement with exhaustive enumeration (with and without assumptions), and
agreement between a reused and a freshly built solver. They exist so that the
later phases fail loudly rather than returning a wrong count.

## Layout

```
cmd/             single-instance solver
cmd/gomibench/   corpus driver: CSV of per-instance results, answer checking, baseline comparison
pkg/gomisat/     the solver
  solver.go        CDCL search, propagation, conflict analysis
  incremental.go   model / core / assumption accessors, budgets, analyzeFinal
  clause.go        clauses and subsumption
  heap.go          activity-ordered variable heap
  dimacs.go        DIMACS parsing
testdata/satlib/ committed instances, expected answer encoded in the names
corpus/          manifest of the larger corpus fetched by scripts/fetch-corpus.sh
bench/           recorded results
```
